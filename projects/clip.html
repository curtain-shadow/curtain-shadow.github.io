跨模态语义聚类与概念发现（CLIP + LLM）

多模态 / 大模型

利用 CLIP 将图像和文本映射到统一语义空间，通过融合策略 + 聚类算法自动发现语义类别，再由 GPT / TF-IDF 生成可读概念标签。

01核心亮点

  • 图文对 → CLIP 统一语义空间映射，实现跨模态对齐
  • 多融合策略 × 多聚类方法 × 多 K 值的对比实验（ACC / NMI 评估）
  • LLM 自动生成聚类语义标签，无 API 时降级 TF-IDF（容错设计）
