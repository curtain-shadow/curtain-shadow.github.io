01核心亮点

  • 5 个 Django app 解耦，体现后端工程化组织能力
  • 自定义用户认证后端 + 验证码注册登录，序列化器 + 分页过滤实现 REST API
  • 关键词搜索 + 纹样分类 + 朝代时间线多维度检索
